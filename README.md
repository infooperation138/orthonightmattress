# ORTHO NIGHT Website

A responsive static website for ORTHO NIGHT mattresses by Super Comfy Mattress.

## Files
- `index.html` — website structure
- `style.css` — design and responsive layout
- `script.js` — WhatsApp enquiry form

## Before publishing
Replace the placeholder email and add your real WhatsApp number in `script.js`.
Also update product specifications, prices, warranty, company address, certifications and any product claims with your actual approved details.

## GitHub Pages
This is a static site and can be published with GitHub Pages from the repository settings.
